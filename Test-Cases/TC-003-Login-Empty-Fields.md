# Test Case: Login con campos vacíos

## ID
TC-003

## Nombre
Validar inicio de sesión con campos obligatorios vacíos

## Objetivo
Verificar que el sistema no permita iniciar sesión cuando el usuario deja los campos de correo y contraseña vacíos.

## Precondiciones
- El usuario debe estar registrado en el sistema.
- La aplicación debe estar disponible.

## Datos de prueba
Correo:
Vacío

Contraseña:
Vacío

## Pasos
1. Abrir la aplicación.
2. Dirigirse a la pantalla de inicio de sesión.
3. Dejar el campo de correo vacío.
4. Dejar el campo de contraseña vacío.
5. Presionar el botón "Iniciar sesión".

## Resultado esperado
El sistema debe mostrar mensajes indicando que los campos son obligatorios y no debe permitir el acceso al usuario.

## Resultado obtenido
Pendiente de ejecución.

## Estado
Pendiente
