# Test Case: Login con contraseña incorrecta

## ID
TC-002

## Nombre
Validar inicio de sesión con contraseña incorrecta

## Objetivo
Verificar que el sistema no permita el acceso cuando el usuario ingresa una contraseña inválida.

## Precondiciones
- El usuario debe estar registrado en el sistema.
- La aplicación debe estar disponible.

## Datos de prueba
Correo:
usuario@test.com

Contraseña:
PasswordIncorrecta123

## Pasos
1. Abrir la aplicación.
2. Dirigirse a la pantalla de inicio de sesión.
3. Introducir un correo válido.
4. Introducir una contraseña incorrecta.
5. Presionar el botón "Iniciar sesión".

## Resultado esperado
El sistema debe rechazar el inicio de sesión y mostrar un mensaje indicando que las credenciales son incorrectas.

## Resultado obtenido
Pendiente de ejecución.

## Estado
Pendiente
