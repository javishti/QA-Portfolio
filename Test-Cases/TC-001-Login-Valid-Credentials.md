# Test Case: Login de usuario

## ID
TC-001

## Nombre
Validar inicio de sesión con credenciales correctas

## Objetivo
Verificar que un usuario pueda iniciar sesión correctamente utilizando un correo y contraseña válidos.

## Precondiciones
- El usuario debe estar registrado en el sistema.
- La aplicación debe estar disponible.

## Datos de prueba
Correo:
usuario@test.com

Contraseña:
Password123

## Pasos
1. Abrir la aplicación.
2. Dirigirse a la pantalla de inicio de sesión.
3. Introducir un correo válido.
4. Introducir una contraseña válida.
5. Presionar el botón "Iniciar sesión".

## Resultado esperado
El usuario debe ingresar correctamente al sistema y visualizar la pantalla principal.

## Resultado obtenido
Pendiente de ejecución.

## Estado
Pendiente
